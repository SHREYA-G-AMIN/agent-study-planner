# 🧠 Agent Study Planner

An AI-powered study planner designed to help students organize their academic schedule efficiently using intelligent agents and data automation.

---

## 🚀 Project Overview

**Agent Study Planner** is a smart platform that allows students to:
- Plan and track their daily study schedule 📚  
- Get personalized learning recommendations 🎯  
- Integrate with academic data sources for adaptive insights 📊  

This project was built as part of the **Hackloop Hackathon 2025**.

---

## 🧩 Role: Data Engineer

As a **Data Engineer**, I handled:
- Designing and maintaining **Firebase Firestore** as the project’s database.  
- Creating and managing **Python scripts** for data ingestion and synchronization.  
- Implementing efficient **data pipelines** for real-time updates and scalability.  
- Managing environment setup with `requirements.txt`.
